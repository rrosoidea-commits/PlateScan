Each row = one recognized plate (plate text, timestamp, confidence scores), stored in SQLite (platescan/platescan.db). Rows are flagged for review when OCR confidence is below 0.80, no text is read, or the text is not a Philippine plate format.

How it works

Every captured frame or uploaded image is sent to the local Python server (FastAPI), which runs the trained models on your GPU and returns the result below. Nothing leaves this computer.

  1. Vehicle detection (YOLO26n, COCO: car, motorcycle, bus, truck)
  2. Plate localization with the trained best.pt detector
  3. Preprocess: crop with a 5% margin (grayscale / CLAHE / threshold shown for inspection)
  4. OCR with fast-plate-ocr → regex check for PH format
  5. Log plate, timestamp and confidences to SQLite

Start: python platescan/server.py → open http://127.0.0.1:8000
